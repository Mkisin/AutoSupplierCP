Требует проверки в Битриксе:
Товарная категория для генератора собирается из полей "Категория товаров компании", 
"Категории товаров для переговоров" и резервно из старого поля "Категория товара".
Категория по работе с сетями сопоставлена с полем "В: Предварительный Регвзнос ПФ", 
потому что точного поля с таким названием в deal_fields.txt не найдено.
Предпочтительные категории сетей сопоставлены с "СЕТИ: Формат", 
потому что точного поля "Предпочтительные категории сетей" в deal_fields.txt не найдено.
Для Render:
BITRIX_WEBHOOK_URL - реальный входящий вебхук Битрикс24 вида https://домен.bitrix24.ru/rest/USER_ID/WEBHOOK_TOKEN/
BITRIX_INBOUND_TOKEN - отдельный секрет для запуска /api/bitrix/webhook из робота Битрикс24.
Робот Битрикс24 для сделки должен вызывать /api/bitrix/deal/webhook?token=BITRIX_INBOUND_TOKEN
Робот Битрикс24 для лида должен вызывать /api/bitrix/lead/webhook?token=BITRIX_INBOUND_TOKEN
Старый адрес /api/bitrix/webhook?token=BITRIX_INBOUND_TOKEN оставлен как совместимый адрес для сделок.
