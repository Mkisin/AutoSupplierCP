# Название проекта **"Авто КП для Поставщика"**
Концепция проекта:
Сервис, который подготавливает для постащика КП по участию в конкретном ЦЗС в виде индивидуальной презентации PPTX и индивидуализированного лэндинга  

## Исходные данные для КП:
Исходные данные делятся на группы.

### Постоянные данные

**Шаблоны презентаций:**
- утвержденный шаблон презентации полный (1)
- утвержденный шаблон презентации краткий (2) 

**Данные базы данных проекта:**
- вся статистика переговоров ЦЗС (3)
- база отзывов клиентов по участию в переговорах на ЦЗС (4)
- данные о переговорах клиента на предыдущих ЦЗС (при наличии) (5)
- данные о сетях и их закупщиках (14)

**Файловое хранилище:**
- база логотитпов (сетей и постащиков) (6)
- база фотографий рабочих моментов ЦЗС с участием закупщиков конкретных сетей. (7)

### Переменные данные 

**Данные о компании**
- предыдущие данные о компании из карточки клиента в Битрикс (8)
- список параметров для подготовки КП, полученных из звонка нашего менежера Клиенту и/или из заявки клинета на наши услуги (Retail Audit) при подготовке к ЦЗС (9)
- данные о компании из базы Контура (по ИНН) (10)

**Данные о конкретном ЦЗС, которое готовится**
- список сетей с разбивкой по категотриям (12) 

**Другие данные**
- результаты оперативных исследований ИИ для конкретной ситуации(11)


## Механика/алгоритм получения КП

**Суть алгоритма**
Сервис:
- принимает задание и переменные данные (о компании и о ЦЗС)
- извлекает и обрабатывает необходимые данные из постоянных источников
- формирует недостающие данные c помощью LLM
- берет нужный шаблон
- поставляет в шаблон данные, которые выбраны или подготовлены для данного КП 
- окончательно формирует и создает файлы PPTX, PDF, HTML
- записывае и отсылает ссылки на документы или сами документы менеджеру
- менеджер проверяет КП и дает к нему доступ или посылает его Клиенту 

Выбор детается ИИ агентом, который использует LLM для обработки и генерации неструктуированной информации и набор программных модулей, разработанных под эту задачу и извлекающих и готовящих информацию из базы данных и файлового хранилища.   

Переменная информация, которая подставляется в шабоны это:
- информация о названии компании, ФИО и должность представителя компании
- конкретная категория товаров, которую поставщик презентует на ЦЗС
- статистика переговоров ЦЗС по этой категории
- выборка из списка сетей, участвующих в данном ЦЗС с учетом категории, задач поставщика и его региона. 
- выборка из отзывов о ЦЗС с учетом категории товаров
- призыв к участию в ЦЗС, подготовленный ИИ индивидуально для этого КП, с учетом всей информации

**Источники данных для подготовки КП**

- каталоги с файлами для проекта (1, 2, 6, 7, 9)
- таблицы или базы данных (3, 4, 5, 14)
- json/XML файл (8, 9, 10, 12 )
- интернет и выдача ИИ  (11)

**Список параметров для подготовки КП** 

Компания/клиент:
- Название компании (обязательно)
- ИНН компании
- тип компании (по типам в Битрикс) (обязательно)
- сфера деятельности (по типам Битрикс) (обязательно)
- отрасль (по битрикс) (обязательно)
- сайт компании (обязательно)
- страна (обязательно)
- город (обязательно)
- категория по работе с сетями (новичок, растущий, опытный) (обязательно)
- годовой оборот компании
- предпочтительный варианты (размер и тип) торговых сетей для входа (множественный выбор из вариантов, например, федеральные сети или Дискаунтеры)

Контакт:
- ФИО контакта (обязательно)
- должность контакта (обязательно)

Товар:
- категория товара  (по категориям Битрикс) (обязательно)
- название товара (обязательно)
- штрихкод товара 
- краткое описание продукции
- ценовая категория товара (первая цена, дискаунтер, средняя, премиум, супер премиум) (обязательно)
- объемы производства
- ссылка на фотографию (если есть)


**Допущения для MVP**
- данные карточки Клиента и список параметров для подготовки КП для целей MVP берем из временной таблицы или заполняем каждый раз руками.
- отзывы для MVP генерируем и используем для тестирования
