# Инструкция по сборке презентации новая

Этот файл — рабочая инструкция для сборки индивидуальной презентации КП по новому шаблону `Шаблон презентации новый.pptx`.

Новая версия отличается от старой тем, что на первом слайде добавлены данные клиента и логотипы сетей, а карта переменных расширена до `{{block27}}` и `{{logo11}}`.

## Цель

Собрать индивидуальную презентацию КП для одной компании из базы проекта на основе шаблона `Шаблон презентации новый.pptx`.

Итоговый файл должен быть PPTX с подставленными данными клиента, статистикой по категории, фотографиями переговоров, отзывами поставщиков, логотипами поставщиков и логотипами сетей.

## Основные входные файлы

- `Данные для разработки.xlsx`
  - лист `Карточка клиента`: карточки компаний и параметры КП;
  - лист `Статистика по группам`: статистика переговоров по категориям.
- `Отзывы.xlsx`
  - источник компаний, ФИО представителей и текстов отзывов для слайда отзывов.
- `Список сетей.xlsx`
  - лист `Shops`;
  - колонка `Компания`: название сети;
  - колонка `Логотип`: имя JPG-файла логотипа сети.
- `Шаблон презентации новый.pptx`
  - основной новый шаблон презентации.
- `Шаблон для вставки новый.md`
  - карта placeholder-переменных нового шаблона.
- `Фотки переговоров/`
  - фотографии для `{{pic2}}`, `{{pic3}}`, `{{pic4}}`, `{{pic5}}`, `{{pic6}}`.
- `Логотипы поставщиков/`
  - логотипы компаний из отзывов для `{{logo1}}`, `{{logo2}}`, `{{logo3}}`.
- `Логотипы сетей/`
  - JPG-логотипы сетей для `{{logo4}}`...`{{logo11}}`.

## Основные скрипты

- `build_payload_new.py`
  - читает Excel и формирует JSON payload с заменами.
  - Использует новую карту `block1..block27` и новые статистические колонки листа `Статистика по группам`.
- `build_presentation_direct_new.py`
  - собирает PPTX напрямую через ZIP/XML, без запуска PowerPoint.
  - Вставляет `{{logo4}}`...`{{logo11}}` из `Список сетей.xlsx` / `Логотипы сетей`.
- `build_gosudarev_presentation.ps1`
  - запасной вариант через PowerPoint COM.
  - Использовать только если прямой Python-вариант не подходит.

## Как выбрать компанию

1. Открыть/прочитать `Данные для разработки.xlsx`, лист `Карточка клиента`.
2. Найти строку по точному названию компании.
3. Если у компании несколько строк с разными контактами, выбрать контакт по приоритету:
   - коммерческий директор / коммерческий отдел;
   - генеральный директор;
   - директор;
   - любой другой контакт.
4. Не выдумывать данные, которых нет в карточке.

## Обязательные поля карточки

Перед сборкой проверить, что для выбранной компании заполнены:

- `Название компании`
- `ФИО контакта`
- `Должность контакта`
- `Категория товара`
- `Название товара`
- `Предпочтительные сети` или другой источник списка сетей для первого слайда

Желательно также проверить:

- `ИНН`
- `Тип компании`
- `Отрасль`
- `Сфера деятельности`
- `Категория по работе с сетями`
- `Сайт`
- `Страна`
- `Город`
- `Ценовая категория`

Если обязательных полей не хватает, сначала дозаполнить карточку или передать значения через override-параметры сборки.

## Placeholder-карта

Использовать соответствия из `Шаблон для вставки новый.md`.

Ключевые текстовые блоки:

- `{{block1}}`: название компании клиента.
- `{{block2}}`: блок получателя: `Получатель`, ФИО контакта, должность контакта.
- `{{block3}}`: категория продукции клиента в формате `«[Категория товара]»`.
- `{{block4}}`: заголовок второго слайда: `переговоров с сетями по категории «[Категория товара]»`.
- `{{block5}}`: персональный заголовок статистики.
- `{{block6}}`: колонка `Контрактов` листа `Статистика по группам`.
- `{{block7}}`: не используется в актуальном PPTX, оставлен как fallback для старых сохраненных шаблонов.
- `{{block8}}`: колонка `Заключенных контрактов на одного поставщика` листа `Статистика по группам`.
- `{{block9}}`: колонка `Закупщики по вашей категории` листа `Статистика по группам`.
- `{{block10}}`: колонка `Федеральных сетей` листа `Статистика по группам`.
- `{{block11}}`: колонка `региональных сетей` листа `Статистика по группам`.
- `{{block12}}`: колонка `Локальный сетей` листа `Статистика по группам`.
- `{{block13}}`: колонка `Хорека` листа `Статистика по группам`.
- `{{block14}}`: колонка `Контрактов всего` листа `Статистика по группам`.
- `{{block15}}`, `{{block16}}`, `{{block17}}`: компания, представитель и текст первого отзыва.
- `{{block18}}`, `{{block19}}`, `{{block20}}`: компания, представитель и текст второго отзыва.
- `{{block21}}`, `{{block22}}`, `{{block23}}`: компания, представитель и текст третьего отзыва.
- `{{block24}}`: имя контакта клиента на финальном слайде.
- `{{block25}}`: колонка `2025 переговоров` листа `Статистика по группам`.
- `{{block26}}`: колонка `2025 контрактов` листа `Статистика по группам`.
- `{{block27}}`: колонка `Средний чек` листа `Статистика по группам`.

Картинки:

- `{{pic2}}`...`{{pic6}}`: фотографии из `Фотки переговоров/`.
- `{{logo1}}`...`{{logo3}}`: логотипы поставщиков из отзывов.
- `{{logo4}}`...`{{logo11}}`: логотипы сетей на первом слайде.

## Как выбирать статистику

1. Взять `Категория товара` из карточки клиента.
2. Найти ближайшую строку на листе `Статистика по группам`.
3. Сначала искать точное/частичное совпадение по названию группы.
4. Если точного совпадения нет, искать по пересечению значимых слов.
5. Если совпадение не найдено, использовать средние значения по листу как временный benchmark и явно указать в отчете `stats_source=average_food_benchmark`.

Для нового шаблона статистику брать из выбранной строки листа `Статистика по группам`:

- `Контрактов` -> `{{block6}}`;
- `Средний чек` -> `{{block27}}`;
- `Заключенных контрактов на одного поставщика` -> `{{block8}}`;
- `Закупщики по вашей категории` -> `{{block9}}`;
- `Федеральных сетей` -> `{{block10}}`;
- `региональных сетей` -> `{{block11}}`;
- `Локальный сетей` -> `{{block12}}`;
- `Хорека` -> `{{block13}}`;
- `Контрактов всего` -> `{{block14}}`;
- `2025 переговоров` -> `{{block25}}`;
- `2025 контрактов` -> `{{block26}}`.

Если в выбранной строке какое-то значение пустое, в отчете сборки нужно явно показать пустое поле и использовать согласованное значение по умолчанию только после проверки.

## Как выбирать сети и логотипы

1. Взять список сетей из поля `Предпочтительные сети` карточки клиента.
2. Если поле пустое, подобрать сети по категории товара и масштабу из `Список сетей.xlsx`.
3. Для каждой сети найти строку на листе `Shops`.
4. Взять имя файла из колонки `Логотип`.
5. Проверить, что файл существует в `Логотипы сетей/`.
6. Заполнить `{{logo4}}`...`{{logo11}}` первыми восемью найденными логотипами.

Если найдено меньше восьми логотипов, допустимо оставить часть placeholders пустыми или вставить нейтральную заглушку, но это должно быть видно в отчете сборки.

## Как выбирать отзывы

1. Из `Отзывы.xlsx` выбрать три отзыва.
2. Приоритет: похожая товарная категория, затем похожий тип компании/ценовой сегмент, затем универсальные отзывы.
3. Не менять смысл отзыва.
4. Не генерировать отзыв от имени реальной компании без источника.
5. Для `{{logo1}}`, `{{logo2}}`, `{{logo3}}` подобрать логотипы соответствующих компаний из `Логотипы поставщиков/`.

## Команда сборки

После доработки скриптов основной вариант должен быть таким:

```powershell
python -X utf8 build_presentation_direct_new.py "Название компании"
```

По умолчанию новый скрипт использует `Шаблон презентации новый.pptx`. При необходимости другой шаблон можно передать через `--template`.

Пример:

```powershell
python -X utf8 build_presentation_direct_new.py "ООО \"БиоФудЛаб\""
```

Проверка без создания PPTX:

```powershell
python -X utf8 build_presentation_direct_new.py --dry-run "Название компании"
```

## Название итогового файла

Рекомендуемый формат:

`[slug компании]_КП_новый_шаблон.pptx`

Если файл уже существует, должен создаваться вариант:

`[slug компании]_КП_новый_шаблон_v2.pptx`, `v3` и так далее.

## Проверка результата

После сборки обязательно проверить:

- файл PPTX создан;
- в выводе есть `text_replaced` больше 0;
- в выводе есть `image_replaced` больше 0;
- `client`, `contact`, `position`, `category` соответствуют выбранной компании;
- на первом слайде подставлены название клиента, блок получателя и логотипы сетей;
- в итоговом файле не осталось видимых placeholder-токенов `{{block...}}`, `{{pic...}}`, `{{logo...}}`;
- все логотипы сетей вставлены из JPG-файлов;
- отзывы и логотипы поставщиков соответствуют друг другу;
- статистика соответствует категории или явно помечена как benchmark;
- изображения не пустые и не сломали структуру слайдов.

## Проверка шаблона

Перед сборкой проверить `Шаблон презентации новый.pptx`.

На слайде `Мы работаем для Вас` в блоке `контрактов заключено в категории` должна использоваться переменная `{{block3}}`, потому что `{{block3}}` — это категория товара.

`{{block15}}` должен использоваться только как название первой компании на слайде отзывов.

Если на пятом слайде вместо категории стоит `{{block15}}`, нужно исправить PPTX:

1. В PowerPoint открыть `Шаблон презентации новый.pptx`.
2. На слайде 5 заменить `{{block15}}` на `{{block3}}`.
3. Сохранить шаблон.
4. Повторно проверить, что `{{block15}}` остался только на слайде отзывов как название первой компании.

## Что нужно доработать в коде

1. `build_payload_new.py` уже обновлен под новую карту `block1..block27`.
2. `build_payload_new.py` уже читает новые колонки листа `Статистика по группам`: `Контрактов`, `Средний чек`, `Заключенных контрактов на одного поставщика`, `Закупщики по вашей категории`, `Федеральных сетей`, `региональных сетей`, `Локальный сетей`, `Хорека`, `Контрактов всего`, `2025 переговоров`, `2025 контрактов`.
3. `build_presentation_direct_new.py` уже читает `Список сетей.xlsx` и подбирает логотипы сетей из `Логотипы сетей/`.
4. `build_presentation_direct_new.py` уже поддерживает image placeholders `{{logo4}}`...`{{logo11}}`.
5. `build_presentation_direct_new.py` поддерживает параметр `--template`.
6. В отчете сборки показывается:
   - какие текстовые placeholders заменены;
   - какие картинки вставлены;
   - какие логотипы сетей не найдены;
   - какие placeholders остались в итоговой презентации.

## Что не делать

- Не редактировать исходный шаблон во время сборки, кроме явного исправления конфликтов placeholder-переменных.
- Не выдумывать реальные ФИО, должности и отзывы.
- Не затирать Excel или презентации пользователя.
- Не использовать случайные изображения из интернета без согласования.
- Не вставлять SVG-логотипы сетей в новый шаблон, использовать JPG из `Логотипы сетей/`.
