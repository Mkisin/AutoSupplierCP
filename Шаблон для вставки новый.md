# Шаблон для вставки новый

Файл описывает переменные из `Шаблон презентации новый.pptx`. В новом шаблоне 8 слайдов. По сравнению со старым вариантом добавлены имя/карточка клиента на первом слайде и логотипы сетей на первом слайде.

## Текстовые блоки

`{{block1}}` вставляем маленькую строку получателя в верхнем левом углу первого слайда: `Получатель ФИО контакта, должность контакта`. Пример: `Получатель Тагиев Гейдар, Партнер`.

`{{block2}}` вставляем большой заголовок первого слайда: `Как компании «Название компании» получить 5-10 контрактов с розничными сетями на Центре Закупок Сетей: WorldFood 2026`.

`{{block3}}` вставляем категорию продукции клиента. Рекомендуемый формат: `«[Категория товара]»`. Эта переменная используется на первом, пятом и восьмом слайдах, включая блок `контрактов заключено в категории`.

`{{block4}}` вставляем заголовок второго слайда: `переговоров с сетями по категории «[Категория товара]»`.

`{{block5}}` вставляем персональный заголовок статистики: `[Имя контакта], ознакомьтесь с итогами последнего ЦЗС™ по категории «[Категория товара]»`.

`{{block6}}` вставляем значение колонки `Контрактов` листа `Статистика по группам`, например `201`.

`{{block8}}` вставляем значение колонки `Заключенных контрактов на одного поставщика` листа `Статистика по группам`, например `7`.

`{{block9}}` вставляем значение колонки `Закупщики по вашей категории` листа `Статистика по группам`, например `63`.

`{{block10}}` вставляем значение колонки `Федеральных сетей` листа `Статистика по группам`.

`{{block11}}` вставляем значение колонки `региональных сетей` листа `Статистика по группам`.

`{{block12}}` вставляем значение колонки `Локальный сетей` листа `Статистика по группам`.

`{{block13}}` вставляем значение колонки `Хорека` листа `Статистика по группам`.

`{{block14}}` вставляем значение колонки `Контрактов всего` листа `Статистика по группам`, например `835`.

`{{block15}}` вставляем название первой компании из подобранных отзывов.

`{{block16}}` вставляем ФИО/представителя первой компании из подобранных отзывов.

`{{block17}}` вставляем текст первого отзыва из `Отзывы.xlsx`.

`{{block18}}` вставляем название второй компании из подобранных отзывов.

`{{block19}}` вставляем ФИО/представителя второй компании из подобранных отзывов.

`{{block20}}` вставляем текст второго отзыва.

`{{block21}}` вставляем название третьей компании из подобранных отзывов.

`{{block22}}` вставляем ФИО/представителя третьей компании из подобранных отзывов.

`{{block23}}` вставляем текст третьего отзыва.

`{{block24}}` вставляем имя контакта клиента для финального слайда. Пример: `Гейдар`.

`{{block25}}` вставляем значение колонки `2025 переговоров` листа `Статистика по группам`, например `241`.

`{{block26}}` вставляем значение колонки `2025 контрактов` листа `Статистика по группам`, например `201`.

`{{block31}}` вставляем значение колонки `Средний чек` листа `Статистика по группам` с одной цифрой после точки, например `10.5`.

## Что нужно сделать, чтобы новый шаблон заработал

1. Проверить переменную в `Шаблон презентации новый.pptx`: на слайде `Мы работаем для Вас` в блоке `контрактов заключено в категории` должна стоять категория `{{block3}}`, а не `{{block15}}`. `{{block15}}` используется только для названия первой компании в отзывах.

2. Для сборки нового шаблона использовать `build_payload_new.py`: он заполняет актуальные блоки до `block31` по новой логике и читает новые статистические колонки листа `Статистика по группам`.

3. Для сборки нового шаблона использовать `build_presentation_direct_new.py`: он вставляет `{{logo1}}..{{logo3}}` из отзывов, `{{logo4}}..{{logo11}}` из `Список сетей.xlsx` / `Логотипы сетей`, а также фото `{{pic2}}..{{pic6}}`.

4. В `build_payload_new.py` уже используется чтение новых статистических колонок листа `Статистика по группам`: `Контрактов`, `Средний чек`, `Заключенных контрактов на одного поставщика`, `Закупщики по вашей категории`, `Федеральных сетей`, `региональных сетей`, `Локальный сетей`, `Хорека`, `Контрактов всего`, `2025 переговоров`, `2025 контрактов`.
